# Documentación de Sculptor

Mapa de esta carpeta. Si vienes a entender el sistema, empieza por `RECORRIDO.md`; si vienes a evaluar una cifra, por `MEDICIONES.md`.

## Sistema (lo que existe en el código)

| Archivo | Qué trae |
| --- | --- |
| [`RECORRIDO.md`](RECORRIDO.md) | Los archivos del repo en el orden en que conviene leerlos |
| [`ARQUITECTURA.md`](ARQUITECTURA.md) | Componentes, rutas de la API, flujo de un dato, agentes, modelos, integraciones y qué es real o simulado |
| [`DECISIONES.md`](DECISIONES.md) | Por qué se eligió cada cosa y qué se descartó |
| [`MEDICIONES.md`](MEDICIONES.md) | Cifras medidas, con cómo, dónde y cuándo. Si una cifra no está aquí, no está medida |
| [`PREGUNTAS.md`](PREGUNTAS.md) | Preguntas probables del jurado con respuestas cortas |
| [`PENDIENTES.md`](PENDIENTES.md) | Lo que sigue abierto o sin verificar |
| [`DISENO.md`](DISENO.md) | Paleta, tipografía y reglas visuales de la app |

## Producto, investigación y marca

| Carpeta | Qué trae |
| --- | --- |
| [`dossier/`](dossier/) | Dossier completo del producto en PDF, con su fe de erratas contra el código |
| [`investigacion/`](investigacion/) | Cómo se llegó a la idea: el plan del Esqueleto Metamórfico, las ideas que se evaluaron y descartaron, y el material del evento |
| [`diseno/sculptor/`](diseno/sculptor/) | Manual y hoja de marca de Sculptor, bocetos de la galaxia |
| [`diseno/nahum/`](diseno/nahum/) | Prototipos del pitch de Nahum: deck interactivo, simulación orbital 3D, prototipo móvil y su guion (en `v2/`, la versión más nueva del deck y la simulación) |
| [`diseno/21st/`](diseno/21st/) | Componentes de 21st.dev elegidos para las páginas de caso |

Los documentos de las carpetas `dossier/`, `investigacion/`, `pitch/` y `diseno/` son material de trabajo de la hackathon: muestran el proceso. Donde no coinciden con el código, vale el código y los documentos de la sección «Sistema».
